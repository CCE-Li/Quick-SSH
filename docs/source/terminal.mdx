# 嵌入式终端

Quick-SSH 提供两种连接方式：

- **在主机列表中按 `Enter`**：退出 TUI，交给系统 OpenSSH 一个全屏交互会话，返回后重新进入 TUI。
- **在 Dashboard 工作台中按 `Enter`**：在 TUI 内部打开**嵌入式终端**，不离开工作台，可以一边看监控一边操作。

嵌入式终端使用 `portable-pty` 分配 PTY（Windows 下为 ConPTY），并用 `vt100` 解析远端输出的 ANSI 序列，因此 vim、htop、less 等全屏程序都能正常使用。

## 打开与关闭

| 操作 | 说明 |
|------|------|
| Dashboard 中按 `Enter` | 连接到选中主机（面板空闲时也可用鼠标点击 Terminal 组件） |
| `Ctrl+Shift+C` | 断开并结束会话 |
| `Ctrl+B` 然后 `q` / `x` | 断开并结束会话 |
| `Esc` | **转发给远端**（例如退出 vim），不是断开 |

连接过程会显示 `${spinner} 正在连接 <别名> …` 的动画；连接建立后显示远程画面。空闲或断开后，面板会显示一个「小电视」待机画面并提示按 `Enter` 重新连接。

面板标题会显示当前状态：

| 状态 | 标题 / 提示 |
|------|------------|
| 连接中 | `<别名> — 连接中` |
| 已连接 | `<别名> — 已连接` |
| 已断开 | `<别名> — 已断开` |

## 前缀键 `Ctrl+B`

在嵌入式终端中，**所有按键默认直接转发给远端 PTY**，TUI 快捷键不生效。要使用 TUI 功能，先按前缀键 `Ctrl+B`（tmux 风格），再按一个命令键：

| 前缀组合 | 功能 |
|----------|------|
| `Ctrl+B` `d` | 打开 Docker 面板 |
| `Ctrl+B` `s` | 打开服务面板 |
| `Ctrl+B` `f` | 打开文件面板 |
| `Ctrl+B` `l` | 打开日志面板 |
| `Ctrl+B` `a` | 打开 AI Agent |
| `Ctrl+B` `k` | 打开命令面板 |
| `Ctrl+B` `q` / `Ctrl+B` `x` | 断开连接 |
| `Ctrl+B` `Esc` | 取消前缀，不执行任何操作 |
| `Ctrl+B` 其他键 | 放行给远端 PTY |

按 `Ctrl+B` 后如果不想执行命令，按 `Esc` 取消；鼠标点击也会取消前缀等待状态。

<Callout title="关闭面板后回到终端">
  从嵌入式终端打开 Docker / 服务 / 文件 / 日志 / Agent 面板后，关闭这些面板时如果 SSH 仍然连接，焦点会自动回到终端，键盘继续转发给远端。
</Callout>

## 滚动回看

终端保留 1000 行回滚历史。

| 操作 | 说明 |
|------|------|
| 鼠标滚轮 | 上下回看历史（每次 3 行） |
| 回看中 | 右上角显示 `↑ 回看中` |
| 滚到底部 | 自动回到实时画面 |

## 密码自动填写

如果该主机在系统凭据库中保存了密码，嵌入式终端也会像普通会话一样，通过 OpenSSH AskPass 自动填写登录密码；OpenSSH 仍会优先尝试密钥和 ssh-agent。

<Callout title="首次连接">
  首次连接新主机时，请先运行 `ssh <别名>` 手动核对并确认主机指纹。Quick-SSH 不会自动回答主机指纹或私钥口令提示。
</Callout>
