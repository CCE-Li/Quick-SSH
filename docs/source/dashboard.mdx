# 工作台（Dashboard）

TUI 有两个视图：经典的主机列表（HostList）和 **Dashboard 工作台**。工作台把一台主机的监控指标、嵌入式终端和运维面板集中在一个可自定义的布局里。

在主界面按 `b` 进入工作台，按 `b` / `q` / `Esc` 返回主机列表。

```
┌ Quick-SSH ───────────────────────────────────────────────────────┐
│ 终端 (mysrv)        │ CPU        Memory       │ AI Agent          │
│                     │ Disk       Network      │                   │
│  root@mysrv:~#      │ Docker     Processes    │ > 查看磁盘占用     │
│                     │ Services   Logs         │                   │
├─────────────────────┴─────────────────────────┴───────────────────┤
│ NORMAL  d Docker s 服务 f 文件 l 日志 a Agent b 主机列表 Esc/q 返回 │
└───────────────────────────────────────────────────────────────────┘
```

工作台监控的是**当前选中的主机**。进入工作台后，后台会以 **2 秒**为周期通过一次 SSH 往返拉取该主机的全部指标（连接超时 5 秒、命令超时 10 秒）。

## 内置组件

<Properties>
  <Property name="CPU" type="Cpu">
    使用率、1/5/15 分钟负载、核心数与频率
  </Property>
  <Property name="Memory" type="Memory">
    总量 / 已用 / 空闲（GB）
  </Property>
  <Property name="Disk" type="Disk">
    各挂载点的已用 / 总量 / 占用率
  </Property>
  <Property name="Network" type="Network">
    RX/TX 速率、IP 与 TCP 连接状态计数
  </Property>
  <Property name="Docker" type="Docker">
    运行中 / 总数，最多显示 8 个容器
  </Property>
  <Property name="Processes" type="Process">
    按 CPU 排序的进程名 / PID / CPU% / 内存
  </Property>
  <Property name="Services" type="Services">
    运行中 / 总数，最多显示 10 个 systemd 服务
  </Property>
  <Property name="Files" type="Files">
    当前目录的 `ls -l` 列表
  </Property>
  <Property name="Logs" type="Logs">
    `journalctl` 最近若干行
  </Property>
  <Property name="System Info" type="SystemInfo">
    操作系统 / 主机名 / 运行时长
  </Property>
  <Property name="Terminal" type="Terminal">
    嵌入式 SSH 终端（详见 [嵌入式终端](/terminal)）
  </Property>
  <Property name="AI Agent" type="Agent">
    AI 运维助手对话面板（详见 [AI Agent](/ai-agent)）
  </Property>
</Properties>

## 布局与 Profile

按 `c` 打开 **Dashboard Configuration** 弹窗，可以勾选启用哪些组件。数字键对应各组件：

| 按键 | 组件 | 按键 | 组件 |
|------|------|------|------|
| `1` | CPU | `6` | Processes |
| `2` | Memory | `7` | Services |
| `3` | Disk | `8` | Files |
| `4` | Network | `9` | Logs |
| `5` | Docker | `0` | System Info |
| `a` | AI Agent | | |

按 `s` / `Enter` 保存。启用 Terminal 时，终端会成为中间主区域，监控组件排在左侧竖列，AI Agent 在右侧。

内置了几套 Profile，可在 [Web 界面](/webui) 中切换：

| Profile | 说明 |
|---------|------|
| **Default** | Terminal + CPU/Memory/Disk/Network/Docker/Process/Agent |
| **Terminal** | 以终端为主，少量监控 |
| **Server Monitoring** | 纯监控：CPU/Memory/Disk/Network/Process/Services/System Info |
| **Docker** | Docker + Logs + CPU/Memory/Network |
| **Minimal** | 仅 CPU/Memory/Network |
| **AI** | Agent + CPU/Memory/Logs |

布局和 Profile 保存在 `dashboard.json`（Windows 为 `%APPDATA%\quick-ssh\dashboard.json`，其余平台为 `~/.config/quick-ssh/dashboard.json`）。

<Callout title="用鼠标拖动分隔线">
  工作台中可以用鼠标按住组件之间的分隔线拖动来调整比例，调整结果会被保存。主机列表与详情之间的分隔线同样可以拖动。
</Callout>

## 运维面板

工作台支持打开一组「运维面板」，它们都基于当前选中主机的实时数据。快捷键在 `NORMAL` 提示条中可以看到。

### Docker 容器（`d`）

列出容器（`●` 运行中 / `○` 已停止 + 名称 + 镜像 + 状态）。

| 按键 | 操作 |
|------|------|
| `j` / `k`、`↓` / `↑` | 上下移动 |
| `r` | 重启容器 |
| `s` | 停止容器 |
| `x` | 删除容器（`docker rm -f`） |
| `q` / `Esc` | 关闭面板 |

重启 / 停止 / 删除会弹出确认框，按 `y` 执行、`n` / `Esc` 取消。

### 系统服务（`s`）

列出 systemd 服务（`●` active / `○` 非 active + 名称 + sub 状态）。

| 按键 | 操作 |
|------|------|
| `j` / `k`、`↓` / `↑` | 上下移动 |
| `a` | 启动服务 |
| `s` | 停止服务 |
| `r` | 重启服务 |
| `q` / `Esc` | 关闭面板 |

同样带确认框。

### 文件浏览（`f`）

浏览远程目录（`ls -l`）。

| 按键 | 操作 |
|------|------|
| `j` / `k`、`↓` / `↑` | 上下移动 |
| `Enter` / `l` / `→` | 进入目录 |
| `h` / `←` | 返回上级目录 |
| `d` | 下载选中文件 / 目录（SCP 到本地当前目录） |
| `q` / `Esc` | 关闭面板 |

### 日志（`l`）

显示 `journalctl` 日志条目（`[unit] 内容`）。

| 按键 | 操作 |
|------|------|
| `j` / `k`、`↓` / `↑` | 上下移动 |
| `r` | 刷新 |
| `f` | 按 unit 过滤（输入框内 `Enter` 应用） |
| `q` / `Esc` | 关闭面板 |

### 远程命令（`:`）

按 `:` 在**选中主机**上执行一条命令（连接超时 5 秒、执行超时 30 秒），结果以弹窗显示退出码与前若干行 stdout / stderr。按 `q` / `Enter` / `Esc` 关闭结果。

## 命令面板（`Ctrl+K`）

按 `Ctrl+K` 打开命令面板，输入关键词即可搜索并执行动作：

- 打开 Dashboard / 返回主机列表
- 编辑 Dashboard 布局
- 打开 AI Agent / Agent 设置
- 全部 Ping 检测
- 添加主机 / 搜索主机
- 退出

上下键选择，`Enter` 执行，`Esc` 关闭。

<Callout title="键盘焦点">
  打开这些面板后，如果 SSH 会话仍然连接，关闭面板会把焦点交还给嵌入式终端；否则回到主机列表。这是刻意的设计，避免打断正在进行的终端会话。
</Callout>
