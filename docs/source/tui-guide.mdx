# TUI 界面指南

Quick-SSH 的 TUI 界面基于 ratatui 和 crossterm 构建，采用事件驱动架构，提供高效的键盘操作体验。

## 视图

TUI 有两个视图，用 `b` 切换：

| 视图 | 说明 |
|------|------|
| **主机列表（HostList）** | 经典的主机列表 + 详情面板，默认视图 |
| **工作台（Dashboard）** | 可自定义布局的监控工作台、嵌入式终端与运维面板 |

## 主机列表布局

```
┌─ 标题栏 ──────────────────────────────────────────┐
│ Quick-SSH v2.0.4  |  共 5 台主机  |  模式: NORMAL  │
├──────────────┬──────────────────────────────────────┤
│              │                                      │
│  主机列表    │           详情面板                    │
│              │                                      │
│  ○ mysrv     │   别名: mysrv                        │
│    生产环境  │   地址: ********                     │
│  ● devbox    │   认证: 密钥优先                     │
│  ○ web-prod  │   注释: 生产环境                     │
│              │                                      │
├──────────────┴──────────────────────────────────────┤
│ 状态栏: j↓ k↑ gg↕ G↕ </>调序 /搜索 :命令 ...       │
└─────────────────────────────────────────────────────┘
```

- **标题栏**：显示版本号、主机数量、当前模式
- **主机列表**：显示所有 SSH 主机、在线状态和首行注释摘要（最多 10 个字符）
- **详情面板**：显示选中主机的地址、密钥、认证方式、状态和完整多行注释
- **状态栏**：显示当前模式的操作提示或闪烁消息

列表与详情之间的分隔线可以用鼠标拖动调整比例。

工作台布局与运维面板的说明见 [工作台（Dashboard）](/dashboard)。

### 主机列表前缀含义

| 图标 | 含义 |
|------|------|
| `○` | 未检测 |
| `●` (绿色) | 在线 |
| `●` (红色) | 离线 |
| `◔` | 检测中 |
| `> ` | 已标记 |

## 交互模式

TUI 支持多种交互模式，通过状态栏可识别当前所处模式：

<Properties>
  <Property name="NORMAL" type="默认模式">
    浏览主机列表或工作台，可使用所有导航和操作快捷键
  </Property>
  <Property name="SEARCH" type="搜索模式">
    输入关键词过滤主机列表，实时筛选
  </Property>
  <Property name="ADD / EDIT" type="新增/编辑模式">
    弹窗表单编辑主机字段，支持 Tab 切换字段，Ctrl+S 保存
  </Property>
  <Property name="CONFIRM" type="确认模式">
    删除确认对话框，按 y/Y 确认，n/N/Esc 取消
  </Property>
  <Property name="HELP" type="帮助模式">
    显示键盘快捷键帮助弹窗，按 q/Esc 关闭
  </Property>
  <Property name="PALETTE" type="命令面板">
    Ctrl+K 打开，搜索并执行动作
  </Property>
  <Property name="DASHBOARD_CFG" type="工作台配置">
    勾选要显示的监控组件
  </Property>
  <Property name="DOCKER_OPS / SERVICE_OPS / FILE_OPS / LOG_OPS" type="运维面板">
    Docker、服务、文件、日志面板，详见工作台文档
  </Property>
  <Property name="AGENT_OPS / AGENT_CFG / AGENT_CONFIRM" type="AI Agent">
    AI 助手对话、设置与审批
  </Property>
  <Property name="COMMAND / CMD_RESULT" type="远程命令">
    在选中主机上执行命令并查看结果
  </Property>
  <Property name="TERMINAL" type="嵌入式终端">
    在 TUI 内使用 SSH 会话，键盘默认全部转发给远端
  </Property>
</Properties>

## 完整快捷键

### 导航

| 按键 | 功能 |
|------|------|
| `j` / `↓` | 向下移动 |
| `k` / `↑` | 向上移动 |
| `Ctrl+N` | 向下移动 |
| `Ctrl+P` | 向上移动 |
| `gg` | 跳到顶部 |
| `G` | 跳到底部 |
| `<` / `>` | 在配置中上/下调整选中主机的顺序（仅主机列表） |

### 主机操作

| 按键 | 功能 |
|------|------|
| `Enter` | 连接选中主机；在主机列表中会退出 TUI 使用全屏 SSH，在工作台中打开嵌入式终端 |
| `Ctrl+Enter` | 在新的终端窗口中连接选中主机（不占用当前 TUI） |
| `Space` | 标记/取消标记 |
| `a` | 新增主机（主机列表）；打开 Agent（工作台） |
| `e` | 编辑当前主机（弹窗表单） |
| `d` | 无标记时删除选中主机；有标记时批量删除所有标记主机 |
| `.` | 切换地址显示/隐藏（隐私保护） |

### 检测

| 按键 | 功能 |
|------|------|
| `p` | Ping 检测当前主机 |
| `P` | Ping 检测所有主机 |

### 视图与面板

| 按键 | 功能 |
|------|------|
| `b` | 在主机列表与工作台之间切换 |
| `c` | 打开工作台配置（仅工作台） |
| `d` / `s` / `f` / `l` | 打开 Docker / 服务 / 文件 / 日志面板（仅工作台） |
| `Ctrl+K` | 打开命令面板 |
| `Ctrl+A` / `Ctrl+Space` | 打开 AI Agent |
| `:` | 在选中主机上执行远程命令 |

### 搜索与系统

| 按键 | 功能 |
|------|------|
| `/` | 进入搜索模式 |
| `Enter` | 确认搜索 / 执行面板动作 |
| `Esc` | 取消搜索 / 返回上级 / 关闭面板 |
| `q` | 退出 TUI（在工作台中为返回主机列表） |
| `?` | 显示帮助 |

## 新增/编辑主机弹窗

按 `a` 或 `e` 会打开主机编辑弹窗，包含以下字段：

| 字段 | 说明 |
|------|------|
| **Host** | 主机别名（必填） |
| **HostName** | 主机地址（IP 或域名） |
| **User** | 登录用户名 |
| **Port** | SSH 端口（默认 22） |
| **IdentityFile** | 密钥文件路径（自动预填充默认路径） |
| **Password** | 登录密码，仅保存到系统安全凭据库，输入以 `*` 遮罩 |
| **注释（无需输入 #）** | 多行主机注释，保存时自动添加 `#` |
| **其他 SSH 指令** | 多行额外配置，如 `ServerAliveInterval 60` |

### 弹窗操作

| 按键 | 功能 |
|------|------|
| `Tab` / `↓` | 切换到下一字段 |
| `Shift+Tab` / `↑` | 切换到上一字段 |
| `←` / `→` | 移动光标 |
| `Enter` | 跳转到下一字段（仅单行字段） |
| `Ctrl+S` | 保存并关闭弹窗 |
| `Esc` | 取消编辑 |

<Note>
  “其他 SSH 指令”可填写 `ServerAliveInterval`、`ProxyJump` 等配置，但禁止重复填写 `Host`、`HostName`、`User`、`Port`、`IdentityFile` 等托管字段。
</Note>

### 密码字段规则

- 新增主机时留空：不保存密码
- 编辑已有主机时留空：保留已保存密码
- 编辑时输入 `!clear`：删除已保存密码
- 修改主机别名：已保存密码会迁移到新别名

密码不会写入 SSH 配置。OpenSSH 会先尝试配置的密钥和 ssh-agent，只有请求登录密码时，Quick-SSH 才通过 AskPass 提供已保存密码。

## 连接主机

在主机列表中选中主机后按 `Enter` 键即可连接。连接流程：

1. TUI 退出备用屏幕，恢复终端（同时关闭鼠标捕获，避免 Windows 下残留的鼠标事件）
2. 检查当前别名是否有已保存密码；读取失败时回退到普通系统 SSH
3. 启动 SSH 交互式会话，OpenSSH 按自身认证顺序尝试密钥、agent 和密码
4. SSH 退出后自动重新进入 TUI 界面

如果希望连接不占用当前 TUI，可以按 `Ctrl+Enter` 在一个新的终端窗口中打开会话。

在 **工作台** 中按 `Enter` 则不会退出 TUI，而是在面板内打开[嵌入式终端](/terminal)。

<Callout title="首次连接">
  AskPass 只响应登录密码提示，不会自动确认首次连接的主机指纹，也不会填写私钥口令。首次连接请先使用 `ssh <主机别名>` 手动确认指纹。
</Callout>

<Callout title="拖拽上传">
  在 SSH 会话期间，将文件拖入终端窗口即可触发文件上传。详见 [文件上传](/file-upload)。
</Callout>
