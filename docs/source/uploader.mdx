# 上传器

`qssh-uploader` 是 Quick-SSH 的独立文件上传工具，位于 [`qssh-uploader/`](/qssh-uploader/)，是一个独立的二进制 crate。

## 设计目标

- **独立可执行**：与主程序分开构建，可独立使用
- **顺序上传**：逐个文件通过 `scp` 传输
- **原生进度**：`scp` 继承控制台，检测到 TTY 后显示原生传输进度
- **复用密码**：通过 AskPass 复用系统凭据库中保存的密码
- **防闪退**：多种机制确保窗口在出错时不会立即关闭

## 架构概览

```
main()
  → 延迟 300ms（等待控制台初始化）
  → 安装 panic hook（防闪退）
  → run()
    → parse_args()            // 解析命令行参数
    → 打印目标信息
    → for 每个文件:
        → upload_via_scp()    // scp 继承控制台，显示原生进度
        → 打印成功 / 失败
    → 打印汇总（成功数 / 耗时）
```

## 命令行接口

```
qssh-uploader --host <host> [选项] <文件路径>...
```

| 参数 | 说明 |
|------|------|
| `--alias <alias>` | 主机别名，用于 AskPass 读取已保存密码 |
| `--host <host>` | 服务器地址（**必填**） |
| `--user <user>` | SSH 用户名 |
| `--port <port>` | SSH 端口（默认 22） |
| `--key <path>` | 密钥文件路径 |
| `--remote-dir <dir>` | 远程目录（默认 `.`） |
| 位置参数 | 要上传的本地文件（**至少一个**） |

未指定 `--host` 或没有文件时会直接报错退出。

## 顺序上传

`run()` 逐个文件调用一次 `upload_via_scp()`：

```rust
for (i, file) in args.files.iter().enumerate() {
    println!("[{}/{}] 上传 {} ...", i + 1, total, name);
    match upload_via_scp(&file_args) { /* 成功 / 失败计数 */ }
}
```

### 上传实现

`upload_via_scp()` 使用系统 `scp`，目标为 `[user@]host:remote_dir/filename`：

```bash
scp -P <port> -i <key> -o ControlMaster=no <local_file> [user@]host:remote_dir/filename
```

- 端口为 22 时省略 `-P`
- `-o ControlMaster=no` 避免与现有 SSH 会话冲突
- 不管道化 stdout/stderr，让 `scp` 检测到 TTY 并显示原生进度；需要密码时也能直接在窗口内输入

### AskPass 复用

指定了 `--alias` 时，`configure_scp_askpass()` 把同目录下的 `qssh(.exe)` 设为 AskPass 程序：

| 环境变量 | 值 |
|---------|----|
| `SSH_ASKPASS` | 同目录的 `qssh.exe` |
| `SSH_ASKPASS_REQUIRE` | `force` |
| `QSSH_ASKPASS_ACTIVE` | `1` |
| `QSSH_ASKPASS_ALIAS` | 主机别名 |
| `DISPLAY` | 缺失时设置为 `qssh-askpass` |

## 防闪退机制

- **启动延迟**：`sleep(300ms)` 等待控制台窗口初始化完成
- **Panic hook**：捕获 panic 后写入日志并循环等待 Enter
- **错误处理**：`run()` 出错时打印错误链，窗口由调用方的 `cmd /c ... & pause` 保持打开
- **日志记录**：所有错误信息同时写入 `%TEMP%\qssh-uploader.log`

## 与主程序的集成

`qssh` 主程序在检测到拖拽文件操作时，在新控制台窗口中启动上传器，并传入别名与目标参数：

```
qssh-uploader --alias <alias> --host <host> [--user <u>] [--port <p>] [--key <k>] --remote-dir <dir> <files...>
```

上传结束后由 `cmd.exe ... & pause` 保持窗口打开，方便查看结果。
